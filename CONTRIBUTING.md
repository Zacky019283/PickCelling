# Contributing to Pick-celling

First off, thank you for considering contributing to Pick-celling! It's people like you that make open-source software such a great community.

## How Can I Contribute?

### Reporting Bugs
This section guides you through submitting a bug report. Following these guidelines helps maintainers and the community understand your report and reproduce the behavior.
*   **Check if the bug has already been reported:** Search the [Issues](https://github.com/Zacky019283/PickCelling/issues) tab to see if someone else has already created a ticket.
*   **Open a new issue:** If you can't find an existing issue, click "New Issue" and select the **Bug report** template. Fill out the form as completely as possible, including screenshots or error logs.

### Suggesting Enhancements
This section guides you through submitting an enhancement suggestion for Pick-celling.
*   Open a new issue and select the **Feature request** template. Explain the problem you are trying to solve and how your proposed feature would help.

### Pull Requests
If you want to write code and fix a bug or add a feature yourself, please follow these steps:
1.  **Fork the repository** and create your branch from `master`.
2.  If you've added code that should be tested, add tests (if applicable).
3.  Ensure the code builds successfully using **.NET 10 SDK**.
4.  **Issue a Pull Request** with a clear description of what you changed and why.

## Development Setup
To build Pick-celling locally:
1. Ensure you have [.NET 10 SDK](https://dotnet.microsoft.com/download) and Visual Studio 2022 installed.
2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/PickCelling.git`
3. Open `Pick-celling.sln` in Visual Studio.
4. Press `F5` to build and run.

## Coding Guidelines
*   Keep the code clean and well-commented where necessary.
*   Follow standard C# naming conventions (PascalCase for methods/classes, camelCase for local variables).
*   This project uses **WinForms**. Try to ensure UI changes look good in both standard and dark modes.

## Code of Conduct
By participating in this project, you are expected to uphold our [Code of Conduct](CODE_OF_CONDUCT.md). Please read it to understand what actions will and will not be tolerated.

## Questions?
If you have any questions, feel free to open an issue with the `question` tag or reach out to the maintainer **(@Zacky019283)** directly on GitHub.

Thank you for your contributions!
